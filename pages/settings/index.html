群聊权限门禁

群主 / 群管理（单独开关）+ 白名单成员才能和机器人对话

这套规则怎么运作

一条群消息进来时，本插件会先判断「发消息的人是谁」： 群主 / 群管理（有单独开关）、AstrBot 全局管理员、 白名单成员 放行；其余成员按当前群的处理模式处理。 未授权成员的 @ 与唤醒词都会被拦下，不会唤起 AI。

四种处理模式

    判定动作含义

    开关

    没在「按群配置」里单独设置的群，都用这里的默认值。

    处理模式与文案

    白名单

    全局白名单对所有群生效；只想让某个人在某个群免拦截，请到「按群配置」里填。 ID 就是 QQ 号一类的用户 ID（纯数字即可），群友可以用 sid 指令自己查。

    角色识别（高级）

    OneBot v11 系适配器（NapCat / Lagrange / go-cqhttp 等）的群消息自带 sender.role， 插件会直接读，不会额外请求接口。只有拿不到时才会调用平台接口查群主/群管理列表。

    分发顺序（高级）

    AstrBot 把一条消息能触发的所有 handler 收集起来，按 priority 从大到小依次调用； 本插件一旦 stop_event()，后面的 handler 全部跳过。 所以「拦得住」的前提是排在前面——默认优先级是 9223372036854775807（sys.maxsize）， 保证排在内置插件之前。调低它就会开始受插件加载顺序影响。

    群列表

    这里列出机器人见过的群和已经单独配置过的群。没配置过的群显示「跟随全局」。

    恢复全局：只清掉本群的单独配置，这一行会留着（因为机器人记得见过这个群） 删除记录：把这一行连同「见过的群」记录一起删掉 清理未配置的群记录：一次性删掉所有「没见过也没配置」的行
    平台 群号 备注 / 群名 启用 模式 群主管理放行 白名单 操作
